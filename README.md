# ORVIN

Mimari tasarım ve proje portföyü.

## Çalıştırma

Node.js 22 veya üzeri. Harici paket gerektirmez.

- `npm run dev`: yerel önizleme (4173)
- `npm run build`: Vercel için dist çıktısı

## Vercel

GitHub deposunu içe aktarın; framework Other, build npm run build, output dist. Ayarlar vercel.json içinde hazırdır.

Taslak yayın arama motorlarına kapalıdır. Alan adı ve yayın metinleri tamamlandıktan sonra HTML noindex ve X-Robots-Tag birlikte gözden geçirilmelidir. E-posta henüz aktif değildir.

Ortak Alan uygulanmış kişisel portföy projesidir; diğer üç proje konsept çalışmasıdır.
